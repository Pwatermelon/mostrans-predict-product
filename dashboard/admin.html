Эмулятор в стеке слушает TCP :9000 и сам шлёт ~12 ТС. Отдельный docker-load из датасета (ndtp-telemetry-emulator.tar) не обязателен — наш контейнер emulator уже поднят.

1. Загрузить исторический / тестовый поток

JSON-массив, JSON Lines или CSV с колонками vehicle_id,route_id,lat,lon,speed_kmh (опц. ts,course,doors_open,schedule_delay_sec). Кадры уходят в тот же пайплайн, что эмулятор → признаки → ML → алерты на пульте.

2. Как жюри подаёт поток

  • Эмулятор (по умолчанию): docker compose up --build — поток уже идёт.
  • Исторический датасет: загрузить файл выше или POST /api/v1/telemetry/batch (Swagger /docs).
  • Прогнозы и алерты: пульт / после входа dispatcher / demo.
  • Метрики latency: GET /api/v1/metrics или шапка пульта.
