Инструкция для жюри

МосТранс Предикт — прогноз задержки ТС за 10–15 минут: ML-ядро + Backend + BI-дашборд.

0. Академическая честность DS (потоковая ML)

Файл submission.csv построен моделью delay_catboost_ds.cbm — той же, что обслуживает POST /predict в контейнере ml.

  • Признаки: FEATURE_COLS (см. GET http://localhost:8001/feature_cols)
  • Анти-утечка: только телеметрия / состояние на момент T
  • Проверка parity: python scripts/verify_stream_parity.py --url http://localhost:8001
  • В шапке дашборда и в GET /api/v1/metrics поле ml_model
curl -s http://localhost:8001/info | python3 -m json.tool

1. Запуск

docker compose up --build

2. Куда смотреть

  • Дашборд диспетчера — карта, треки, таблица ТС, алерты, what-if, сообщения водителю
  • Кабинет водителя — мобильный вид: задержка, скорость, inbox
  • Swagger · submission.csv
  • Эмулятор NDTP: TCP :9000

3. Поток телематики

Эмулятор шлёт 12 ТС. Либо POST /api/v1/telemetry / /telemetry/batch.

4. Прогнозы и действия диспетчера

  • Инциденты + цвет green/yellow/red, статус в пути / остановка / обед
  • Карточка: горизонт 10–15 мин, причина, реком. скорость, сообщение водителю
  • What-if: выпуск доп. ТС

5. Надёжность

docker compose stop emulator — режим degraded/historical без падения сервиса.
