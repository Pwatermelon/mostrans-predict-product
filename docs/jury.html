Инструкция для жюри

МосТранс Предикт — прогноз задержки ТС за 10–15 минут: ML-ядро + Backend + BI-дашборд.

1. Запуск (одна команда)

docker compose up --build

Первый старт ML может занять 1–2 мин (bootstrap CatBoost + PyTorch + ONNX).

2. Куда смотреть

  • Дашборд диспетчера — карта, ТС, алерты, what-if
  • Swagger / OpenAPI — пробный запрос GET /api/v1/health
  • Метрики latency
  • submission.csv — готовый сабмит для раздела Data Science
  • Эмулятор NDTP: TCP localhost:9000 (JSON Lines)

3. Как подать поток

Автоматически: эмулятор уже крутит 12 ТС по 4 маршрутам Москвы.

Вручную (исторический датасет):

curl -X POST http://localhost/api/v1/telemetry/batch \
  -H 'Content-Type: application/json' \
  -d @your_frames.json

Или один кадр: POST /api/v1/telemetry (см. Swagger).

4. Где прогнозы и алерты

  • Правая колонка «Инциденты» — ТС с высокой вероятностью задержки
  • Клик по карточке / маркеру — причина, горизонт 10–15 мин, рекомендация
  • Цвет маршрута и маркера: зелёный / жёлтый / красный
  • What-if — оценка выпуска +1…+3 ТС

5. Надёжность

Остановите контейнер emulator — backend уйдёт в degraded/historical без падения и восстановится после реконнекта.
