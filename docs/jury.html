Как смотреть решение

МосТранс Предикт: прогноз опоздания на 10–15 минут. ML + backend + пульт. Прод: hackton-test.ru.

Модель = сабмит

submission.csv собран той же delay_catboost_ds.cbm, что отвечает на POST /predict. Признаки только на момент T. Проверка: scripts/verify_stream_parity.py.

1. Запуск

docker compose up --build

Или сразу сайт. Вход: /login — dispatcher / demo.

2. Поток

Эмулятор в compose сам шлёт ~12 ТС на TCP :9000. Историю можно залить на /admin (JSON/CSV) или через POST /api/v1/telemetry/batch.

3. Прогнозы и алерты

  • Пульт — карта, таблица ТС, инциденты (зелёный/жёлтый/красный)
  • Клик по ТС — горизонт, причина, реком. скорость, сообщение водителю
  • Кабинет водителя (телефон): вход driver-1000 / demo → /driver — риск, чек-лист, быстрые ответы
  • Статистика — где проблемы по сети
  • Метрики: шапка пульта или GET /api/v1/metrics
